# intimoi 双相 — 设计系统

> 高端电商微信小程序的设计系统。品牌名 **intimoi / 双相**，主营美妆、女装等高端品类（客单价 ¥800–3000）。

---

## 品牌定位

**intimoi（双相）** 是一个面向高端消费人群的精选电商品牌。中文名"双相"取自物理学概念，暗示品牌的双重面相：**理性的克制** 与 **感性的优雅** 并存。

- **目标人群**：25–40 岁女性，审美成熟，对品质与设计敏感
- **核心品类**：美妆护肤、女装配饰（拓展至家居、香氛）
- **价位带**：¥800–3000（高端 / 轻奢）
- **载体**：微信小程序（iOS / Android）

## 内容基调（Content Fundamentals）

### 语气 / Tone

**克制、高冷、信息优先。** 文案以产品名 + 参数为主，不用形容词堆砌，不煽情，不喊口号。像奢侈品官网或博物馆的商品说明，而非直播间话术。

### 人称

避免使用"您""亲"等称谓。需要指代用户时用简短的直接表达（"已下单""请选择规格"），不用"你的订单"式的对话感。

### 大小写 / 符号

- 英文品牌名 `intimoi` 全小写
- 中文品牌名 `双相` 仅作辅助使用（logo、页脚）
- 不使用 emoji（❌）
- 不使用感叹号除极少数场景（如支付失败提示）
- 数字、货币符号用半角：`¥1,280`
- 破折号统一用 `—`（em dash），不用 `--`

### 文案示例

| ❌ 不要这样写 | ✅ 这样写 |
|---|---|
| 亲，您的订单已经成功支付啦🎉 | 支付成功 |
| 超值爆款！限时特惠！ | 精选 · 本月上新 |
| 快来加入我们的会员吧～ | 会员 |
| 您的购物车里还有 3 件商品 | 购物车 3 |
| 哎呀，支付失败了 | 支付未完成 |
| 立即抢购 | 结算 |
| 今日推荐好物 | 编辑精选 |

### 文字节奏

- 标题用短句（4–8 字），不加标点
- 正文段落简短，信息分行
- 产品描述先说品类 / 材质 / 产地，再说设计理念，最后才是情绪化表达

## 视觉基础（Visual Foundations）

### 色彩

**主色：薰衣草淡雅紫系**（柔和、低饱和、雅致）
- 主色 `#B8A3E0`（薰衣草）
- 深色变体 `#6B5B8E`（用于强调文字、按钮）
- 浅色背景 `#F5F1FA`（整体页面底色）

**中性色** 以暖灰为主，避免纯黑 — 保留高级感。
**点缀色** 极少使用，仅在价格红、支付状态等必要场景。

详见 `colors_and_type.css`。

### 字体

**使用微信小程序系统默认字体栈**（苹方 / PingFang SC on iOS、思源黑体 on Android、系统英文字体）。不引入自定义中文 webfont，保证小程序性能与一致性。

- 标题层级通过 **字重 + 字号 + 字距** 拉开差异
- 大标题偏细、偏大（做"呼吸感"）
- 正文克制、规整

### 间距

以 `4px` 为基本模数，常用尺度：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 48 / 64`。页面左右安全边距统一 `20px`。

### 圆角

**极锐利：0px。** 所有卡片、按钮、输入框、图片均为 **直角**。这是品牌的核心视觉主张 — 区别于市面多数消费类小程序的"柔和圆角"，强化高端冷静气质。

唯一例外：头像、品牌徽章使用圆形（50%）。

### 毛玻璃 / 背景

**毛玻璃仅用于关键位置：**
1. **顶部导航栏**（scroll 后 `backdrop-filter: blur(20px) + 50% 白色半透明`）
2. **底部 Tab Bar**（常驻毛玻璃，与内容层分离）

其他场景（卡片、弹窗）不使用毛玻璃，保持视觉层级简单。

**背景** 采用 `#F5F1FA` 淡紫色柔和底色，在首页顶部叠加一层 **大型柔光圆形径向渐变**（#E8DFF5 → 透明），制造细腻的光晕氛围，但不抢商品主体。

### 动效

- **不用弹跳 / 回弹动画**（破坏克制感）
- 过渡统一 `300ms cubic-bezier(0.2, 0.8, 0.2, 1)`（平滑出入）
- 页面切换：淡入 + 极轻的位移（8px）
- 按钮按下：`scale(0.98)` + 80% 透明度（不用颜色变化）

### 状态

- **Hover / Press**：透明度降到 `0.7`，**不改变颜色**
- **Disabled**：透明度 `0.3`，不变灰
- **Focus**（输入框）：下划线变深紫 `#6B5B8E`，不用 outline 框

### 边框 / 阴影

- **边框** `1px solid rgba(107, 91, 142, 0.12)`（极细、低对比）
- **阴影系统** 极克制：
  - `sm`：`0 1px 2px rgba(107, 91, 142, 0.04)`
  - `md`：`0 4px 16px rgba(107, 91, 142, 0.06)`（毛玻璃层使用）
  - `lg`：`0 12px 40px rgba(107, 91, 142, 0.08)`（弹窗）
- 不使用内阴影（inset）

### 卡片

- 直角（`border-radius: 0`）
- 白色背景或略浅于页面底色
- 极细边框或完全无边框 + 轻阴影
- 图片与文字之间 `16px` 间距
- 图片长宽比统一 `3:4`（商品卡）或 `1:1`（banner 小图）

### 透明度与模糊

- **毛玻璃层**：`backdrop-filter: blur(20px) saturate(180%)`，`background: rgba(255,255,255,0.5)`
- **遮罩层**（弹窗底）：`rgba(0,0,0,0.3)`
- 商品图片、文案，从不使用模糊

### 图片调性

- **冷调 + 高级灰**，不用暖阳 / 橙调滤镜
- 保留少量颗粒感（grain）模拟胶片
- 背景留白多，主体居中
- 模特图避免"商业正微笑"，偏向杂志风、人物视线不看镜头

### 布局规则

- 固定元素：顶部导航（毛玻璃）+ 底部 Tab（毛玻璃，仅一级页面）
- 页面最大宽度：小程序默认（375 设计稿 / 750rpx）
- 首页按"杂志感"：大图 banner + 编辑精选（瀑布流较少）
- 列表页每行 2 列商品卡

## 图标（Iconography）

- **线性图标为主**，1.5px 描边，直角端点（`stroke-linecap: square`）
- **使用 Lucide Icons**（CDN 加载）作为基础图标集 — 其克制的线性风格与品牌调性一致
- 关键功能图标（Tab、购物车、收藏、搜索）从 Lucide 中挑选后统一为 **24×24** 尺寸
- 不使用填色图标、不使用多色图标、不使用 emoji
- 角标 / 徽章用纯数字 + 深紫小圆点（唯一例外的圆形元素）

> **说明**：Lucide 作为开源 CDN 图标集，与 intimoi 的设计语言匹配度高（简线、锐利、克制）。如未来做品牌定制图标，可基于 Lucide 的几何原则延展。

## 使用方式

1. 在 HTML 中 `<link rel="stylesheet" href="colors_and_type.css">` 即可获得所有 CSS 变量
2. 直接读取 `ui_kits/miniprogram/*.jsx` 作为 React 组件复用
3. 品牌素材从 `assets/` 复制使用，不要直接 link（做成下游项目的副本）
